- **Keepalive**: Tickle/Tickle-Ack maintaining stable connections
- **Data forwarding**: Both inbound (AURP→Local) and outbound (Local→AURP) implemented

## Why File Shares Aren't Showing Up Yet

**The NBP forwarding code is implemented and running**, but it's not being exercised because:

1. **No AppleTalk clients are connected** to the local network (650.37)
2. **No NBP lookups are being made** from vintage Mac clients
3. **The code path won't execute** until a Mac uses Chooser to browse remote zones

The implementation is like a bridge that's been built but has no cars driving across it yet.

## Test Instructions

### Prerequisites
- Vintage Mac (System 7, 8, or 9) with LocalTalk/EtherTalk
- Mac connected to network 650 (same L2 as enp12s0)
- AppleTalk control panel configured for EtherTalk

### Test Procedure

1. **Verify Mac can see local zone**:
   ```
   - Open Chooser
   - Click AppleShare
   - Should see "netjibbing" zone
   ```

2. **Test remote zone browsing**:
   ```
   - In Chooser, select zone dropdown
   - Should see 11 zones listed
   - Select "SNAKSrV" or "PurrTopia"
   - Wait for server list to populate
   ```

3. **Expected behavior**:
   - NBP broadcast generated by Mac
   - atalkd detects AURP route for remote zone
   - NBP forwarding code builds DDP packet
   - Packet sent through AURP tunnel
   - Remote servers respond
   - Servers appear in Chooser

4. **Monitor logs during test**:
   ```bash
   sudo journalctl -u atalkd -f | grep -E "nbp brrq|aurp_send_data|aurp_handle_data"
   ```

   You should see:
   ```
   nbp brrq: forwarded to AURP network 4123
   aurp_send_data: sent 67 byte packet to 63.228.98.61 for network 4123
   ```

## Troubleshooting

### If servers don't appear:

1. **Check zone visibility**:
   ```bash
   getzones
   # Should show 11 zones
   ```

2. **Verify AURP connections**:
   ```bash
   sudo journalctl -u atalkd | grep "AURP Totals"
   # Should show 9 connected peers
   ```

3. **Check for NBP activity**:
   ```bash
   sudo journalctl -u atalkd -f | grep nbp
   # Should see NBP packets when using Chooser
   ```

4. **Capture AURP traffic**:
   ```bash
   sudo tcpdump -i enp12s0 -n udp port 387 -w /tmp/test.pcap
   # During Chooser browsing, should see packets > 50 bytes
   ```

## Known Limitations

1. **Peer availability**: Only ~10% of community peers respond (19 out of 173)
2. **No jrouter dependency**: atalkd operates independently
3. **Linux only**: Uses Linux kernel AppleTalk stack
4. **Testing gap**: End-to-end data forwarding unverified without physical Mac
